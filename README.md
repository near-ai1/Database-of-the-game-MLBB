# База персонажей MLBB

Статический каталог персонажей Mobile Legends: Bang Bang с поиском, фильтрами, темами оформления и русским, английским и узбекским интерфейсом. Переключатель также показывает Dota 2, Genshin Impact и Zenless Zone Zero; их отдельные каталоги будут добавляться по очереди. Пока доступны только данные MLBB. Вход и личные аккаунты не требуются.

Интерфейс, титулы персонажей, даты выхода, предметы и контрпики переключаются вместе с языком. Имена героев и названия регионов сохраняются как в игре; краткие описания оставлены на исходном английском, поскольку проверенного перевода для них нет.

В разделе «Настройки графики» можно посмотреть общие рекомендации для телефона/планшета, ПК, ноутбука, Xbox и PlayStation, отдельно выбрав максимальное качество или плавность. Сайт не измеряет производительность устройства и не меняет настройки игры автоматически; MLBB также не имеет официальной версии для Xbox или PlayStation.

## Запуск

Откройте сайт через локальный HTTP-сервер или хостинг. Например, из этой папки выполните `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Не открывайте `index.html` через `file://`: каталог загружается из `heroes.json`.

## Каталог персонажей

`heroes.json` содержит 132 уникальных героя с ролями, специализациями, рекомендуемыми линиями, титулами, регионами, датами выхода, описаниями, шкалой сложности, типом урона и боевыми характеристиками уровней 1 и 15. Список и характеристики основаны на [перечне героев](https://mobile-legends.fandom.com/wiki/List_of_heroes) и [данных персонажей](https://mobile-legends.fandom.com/wiki/Module:Hero/data) Mobile Legends Wiki. Краткие описания доступны для 130 персонажей; для Nana источник не содержит числовую сложность, а у Nana и Marcel нет описания.

Списки предметов и сложных матчапов теперь есть у всех 132 героев. Для ранее пустых карточек рекомендации добавлены из открытого [снимка статистики MLBBDex](https://github.com/achedon12/mlbb/blob/e24924306cd1e42766d37fa56974d93dda82bede/src/data/game/statistics.json): предметы взяты из внутриигрового руководства для основной линии, а сложные противники — из списка измеренных матчапов. Данные статистики датированы 28 сентября 2026 года. Это ориентиры на основе данных сообщества, а не гарантированный оптимальный выбор; они могут измениться после обновлений игры.
